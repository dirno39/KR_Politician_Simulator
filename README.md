# 이번 생은 정치다

2027년 1월 정계에 입문해 은퇴하는 날까지, 한 정치인의 인생을 6개월 단위로 살아 보는 모바일 웹 시뮬레이션 게임입니다.
모든 정당과 인물은 가상이며, 선거 제도와 일정만 현실을 참고했습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. 폴더를 아무 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 4173
```

그다음 브라우저에서 `http://localhost:4173` 을 엽니다.

## 배포

폴더 전체를 정적 호스팅에 올리면 끝입니다. 서버, 데이터베이스, 환경 변수가 없습니다.

- **Cloudflare Pages / Netlify / Vercel**: 이 폴더를 저장소로 올리고, 빌드 명령 없이 출력 디렉터리를 루트(`/`)로 지정합니다.
- **GitHub Pages**: 저장소 Settings → Pages 에서 브랜치 루트를 선택합니다.

스크립트를 고친 뒤 다시 배포할 때는 `index.html` 의 `?v=2.0.0` 과 `plus.js` 의 `VERSION` 을 함께 올려 브라우저 캐시를 갱신합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀과 스타일 전부 |
| `data.js` | 정당, 지역구, 컨셉 카드 등 데이터 테이블 |
| `game.js` | 턴 진행, 능력치, 선거 계산, 저장 |
| `content.js` | 기회 일정, 이벤트, 속보, 개헌·계엄, 선거 결과 공표, 입당·창당, 칭호 도감 |
| `plus.js` | 정국 화두, 미니게임, 토론, 선거 캠프(전략·돌발·마지막 유세), 연혁 화면, 설정 |
| `design.js` | 전용 아이콘, 도장·투표용지 효과, 개표방송, 이벤트 연출, 미니게임 3종, 출마 지역 권역 탭 |
| `more.js` | 버티기형·연쇄 이벤트, 비례대표, 전직 대통령의 퇴임 후 정치 |
| `patch2.js` | 약점 게이지와 수사·재판, 유혹 이벤트, 직책별 과업(상임위·법안, 시정 사업, 내각·국정과제), 큰 무대 전용 미니게임 |
| `manifest.webmanifest`, `icon.svg` | 홈 화면 추가용 정보와 아이콘 |

## 저장

진행 상황은 반기가 시작될 때마다 브라우저 `localStorage` 에 저장됩니다. 서버로 전송되는 데이터는 없습니다.
설정 화면에서 저장 데이터와 칭호 도감을 지울 수 있습니다.

## 밸런스 조정

숫자는 대부분 `data.js` 와 각 파일 상단의 상수에 모여 있습니다.

- 지역 지형(`L`), 컨셉 카드 능력치: `data.js`
- 공천 확률 `nomProb`, 득표 계산 `rawOf`: `game.js`
- 상대 캠프 보정 `NPC_CAMP`, 창당 인지도 기준 `FOUND_FAME`: `plus.js`, `content.js`
